# Initializing

Open a CMD window and navigate to your exercise folder, in my case __C:\Users\student\Desktop\Exercise1>__.

I type the command

````dos
git init
````

to initialize the repo. Type the command

````dos
dir /a
````

to see hidden files.

If I type 

````dos
cd .git 
dir
````

I can see the git files and directories.

Type

````dos
cd ..
````

to get back to the Exercises1 folder, then type

````dos
git –help
````

to see the available options.
